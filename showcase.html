✨ ฟีเจอร์หลักของระบบ

🔐

ระบบล็อกอิน

รักษาความปลอดภัยข้อมูลด้วยระบบล็อกอินแบบ secure เฉพาะเจ้าหน้าที่สามารถเข้าใช้ได้

👥

รายชื่อสมาชิก

แสดงตารางรายชื่อสมาชิกทั้งหมดพร้อมฟัง​ชันค้นหา ดูรายละเอียด และแก้ไขข้อมูล

➕

เพิ่มสมาชิกใหม่

ฟอร์มครอบคลุมพร้อมฟิลด์อากาศแบบไดนามิก validation และการจัดการข้อมูลอัตโนมัติ

📧

รวมอีเมล

แสดงรวมอีเมลของสมาชิกแยกตามประเภท (ทั้งหมด สามัญ วิสามัญ) พร้อมคัดลอกได้ทันที

📊

สถิติสมาชิก

แสดงสถิติอย่างละเอียด: สถานะการศึกษา ระดับการศึกษา ปีที่สำเร็จ และการจัดกลุ่มตามภูมิภาค

📥

นำเข้า Excel

รองรับการนำเข้าข้อมูลจำนวนมากจากไฟล์ Excel พร้อมตัวอย่างและการยืนยัน

⚙️

Auto-calculation

คำนวณสถานะสมาชิกอัตโนมัติตามวันที่สำเร็จการศึกษา

🌐

สตัตัสอัพเดต

หน้าเฉพาะสำหรับติดตามสมาชิกที่ต้องอัปเดตข้อมูลตามการเปลี่ยนแปลงสถานะ

💾

บันทึกอัตโนมัติ

ข้อมูลบันทึกอัตโนมัติใน LocalStorage ไม่ต้องเซิร์ฟเวอร์

ฟอร์มที่รองรับการเพิ่มสมาชิกใหม่ด้วยฟิลด์ที่ปรับตัวตามประเภทของสมาชิก

📧 รวมอีเมล

แสดงรวมอีเมลของสมาชิกแยกตามประเภท พร้อมปุ่มคัดลอกและส่งอีเมล

📊 สถิติสมาชิก

แสดงสถิติอย่างละเอียด ด้วยแผนภูมิและข้อมูลแยกตามหลายมิติ

📥 นำเข้าข้อมูล

รองรับการนำเข้าข้อมูลจากไฟล์ Excel พร้อมตัวอย่างข้อมูลก่อนนำเข้า

🔄 อัปเดตสถานะ

หน้าเฉพาะสำหรับติดตามสมาชิกที่ต้องอัปเดตข้อมูลตามการเปลี่ยนแปลง

💾 บันทึกอัตโนมัติ

ข้อมูลบันทึกอัตโนมัติในเบราว์เซอร์ ไม่สูญหายแม้ปิดเบราว์เซอร์

🎨 UI/UX ที่ดี

ออกแบบมาให้ใช้งานง่าย สวยงาม และตอบสนองได้บนทุกอุปกรณ์

📖 วิธีการใช้งาน

ขั้นตอนการใช้งาน:

  1. เข้าสู่ระบบ: ใช้ username: admin และ password: admin123
  2. ดูรายชื่อสมาชิก: ไปที่หน้า "รายชื่อสมาชิก" เพื่อดูข้อมูลทั้งหมด พร้อมค้นหา
  3. ดูรายละเอียด: คลิกที่แถวสมาชิกใดๆ เพื่อดูข้อมูลครบถ้วน
  4. เพิ่มสมาชิกใหม่: คลิกปุ่ม "เพิ่มสมาชิก" และกรอกข้อมูลตามต้องการ
  5. แก้ไขข้อมูล: คลิก "แก้ไข" จากรายละเอียดสมาชิก
  6. ดูรายชื่ออีเมล: ไปที่หน้า "อีเมลสมาชิก" เพื่อรวบรวมอีเมล
  7. ตรวจสอบสถิติ: ไปที่หน้า "สถิติสมาชิก" เพื่อดูการวิเคราะห์ข้อมูล
  8. นำเข้าข้อมูล: ใช้ปุ่ม "นำเข้า Excel" เพื่อเพิ่มข้อมูลจากไฟล์ Excel
  9. ติดตามอัปเดต: ไปที่หน้า "สมาชิกที่ต้องอัปเดต" เพื่อดูคนที่ต้องแก้ไขข้อมูล

💻 การติดตั้งและการใช้งาน

ขั้นตอนการติดตั้ง:

1. Clone repository:
git clone https://github.com/s2yunn/s2yunn.git

2. เปิดไฟล์ index.html:
เปิดไฟล์ index.html ด้วยเบราว์เซอร์ (ไม่ต้องการเซิร์ฟเวอร์)

3. หรือใช้ HTTP Server (ถ้าต้องการ):
python3 -m http.server 8000

💡 หมายเหตุ:

โปรเจคนี้เป็น Static Site ที่ไม่ต้องการ Backend หรือฐานข้อมูลเซิร์ฟเวอร์ ข้อมูลทั้งหมดจะเก็บไว้ในเบราว์เซอร์ของคุณ (LocalStorage) ดังนั้นจึงมีความปลอดภัยสูง และไม่ต้องเก็บข้อมูลที่ใดก็ได้นอกเบราว์เซอร์
