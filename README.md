# ระบบบันทึกข้อมูลสมาชิก - สมาคมนักเรียนไทยในสาธารณรัฐเกาหลี

## 📋 ภาพรวมระบบ

ระบบนี้เป็นแอปพลิเคชัน **Claims Management System (CMS)** ที่ออกแบบมาสำหรับจัดเก็บและจัดการข้อมูลสมาชิกของสมาคมนักเรียนไทยในสาธารณรัฐเกาหลี โดยมีฟีเจอร์ต่างๆ ดังต่อไปนี้:

### ✨ ฟีเจอร์หลัก

1. **ระบบล็อกอิน** - เฉพาะเจ้าหน้าที่เท่านั้นสามารถเข้าใช้ระบบได้
2. **รายชื่อสมาชิก** - แสดงตารางรายชื่อพร้อมคลิกดูรายละเอียดเต็มรูปแบบ
3. **เพิ่ม/แก้ไขสมาชิก** - ฟอร์มเต็มรูปแบบพร้อม validation
4. **รวมอีเมล** - แสดงอีเมลแบ่งเป็นสมาชิกสามัญและวิสามัญ
5. **สถิติสมาชิก** - แสดงสถิติเป็นเปอร์เซ็นต์หลายมิติ
6. **Auto-calculation** - คำนวณสถานะอัตโนมัติตามวันที่สำเร็จการศึกษา

## 📊 ฟิลด์ข้อมูลสมาชิก

### ข้อมูลการลงบันทึก
- `วันที่เจ้าหน้าที่ลงข้อมูล` - YYYY-MM-DD

### สถานภาพนักเรียน
- `สถานภาพนักเรียนล่าสุด` - เป็น/เคยเป็นนักเรียนระดับชั้นปริญญา หรือ เป็น/เคยเป็นนักเรียนภาษา
- `ระดับที่ศึกษาสูงสุด` - ปริญญาตรี / ปริญญาโท / ปริญญาเอก / อนุปริญญา / Research Student
- `วิชาเอกที่ศึกษา` - ข้อความอังกฤษ

### ข้อมูลส่วนบุคคล
- `คำนำหน้าชื่อ` - นาย / นางสาว / นาง
- `ชื่อจริง-นามสกุล (ไทย)` - ตัวอักษรไทย
- `ชื่อเล่น (ไทย)` - ตัวอักษรไทย (optional)
- `ชื่อจริง-นามสกุล (อังกฤษ)` - ตัวอักษรอังกฤษ
- `ชื่อเล่น (อังกฤษ)` - ตัวอักษรอังกฤษ (optional)
- `วัน/เดือน/ปีเกิด` - YYYY-MM-DD

### ข้อมูลติดต่อ
- `หมายเลขโทรศัพท์` - ตัวเลข 9-15 หลัก
- `อีเมลที่ติดต่อได้` - รูปแบบอีเมลที่ถูกต้อง
- `ที่อยู่ปัจจุบัน` - ข้อความอิสระ (optional)

### ข้อมูลการศึกษา
- `วันที่สำเร็จ/คาดว่าสำเร็จการศึกษา` - YYYY-MM-DD (จำเป็น)
- `มหาวิทยาลัยที่ศึกษา` - ภาษาอังกฤษ
- `ภูมิภาคที่อยู่ในเกาหลี` - 15 ภูมิภาค + ไทย

### สถานะ (คำนวณอัตโนมัติ)
- `สถานะ` - กำลังศึกษา (วันที่ > วันนี้) หรือ สำเร็จการศึกษา (วันที่ ≤ วันนี้)
- `สถานะสมาชิก` - สมาชิกสามัญ (กำลังศึกษา) หรือ สมาชิกวิสามัญ (สำเร็จการศึกษา)

### ข้อมูลเพิ่มเติม
- `เอกสารรับรอง` - Google Drive Link (optional)
- `ชื่อทุนที่ได้รับ` - ข้อความอิสระ (optional)

## ⚙️ Validation Rules

### Date Validation
- รูปแบบ: YYYY-MM-DD
- ต้องเป็นวันที่ที่มีอยู่จริง

### Email Validation
- ต้องมีรูปแบบอีเมล: xxx@xxx.xxx

### Phone Validation
- ต้องเป็นตัวเลข 9-15 หลัก

### Status Auto-Calculation
```
If (วันที่สำเร็จ > วันนี้) → สถานะ = "กำลังศึกษา"
If (วันที่สำเร็จ ≤ วันนี้) → สถานะ = "สำเร็จการศึกษา"

If (สถานะ == "กำลังศึกษา") → สถานะสมาชิก = "สมาชิกสามัญ"
If (สถานะ == "สำเร็จการศึกษา") → สถานะสมาชิก = "สมาชิกวิสามัญ"
```

## 🐛 Troubleshooting

### ข้อมูลไม่ถูกบันทึก
- ตรวจสอบว่า localStorage เปิดอยู่ในเบราว์เซอร์
- ลองลบ localStorage แล้วรีเฟรช

### ไม่สามารถเข้าสู่ระบบ
- ตรวจสอบ username/password ใช้ `admin`/`admin123`
- ล้าง browser cache

### ฟอร์มไม่ทำการสมัครสมาชิก
- ตรวจสอบข้อมูลการตรวจสอบ (validation)
- ดู browser console เพื่อดูข้อผิดพลาด
